# 页面类型

本页用于判断目标页是什么，以及该怎么维护。

## 1. 容器页

### 典型特征

- 内容极短
- 主要承担父页、分类、目录、占位作用
- 子文档多于正文内容

### 处理原则

- 默认不要把大段综合结论写到容器页
- 只有用户明确要做导航页 / 入口页时才扩充
- 优先把实质内容写入子页或知识页

### 母文件 / 索引页

当容器页有多个子文档，且用户要求“整理入口”“做索引”“补目录”时，可以把母文件维护成目录 / 摘要页。

处理原则：

- 母文件本身承担入口页作用，不额外滥建“索引”子文档
- 索引内容直接放在母文件正文
- 快速入口应指向真实存在或已确认的文档 / 块
- 不把容器页误当成项目知识页写入大段结论

推荐结构：

```markdown
## 摘要
## 快速入口
## 近期活跃
## 结构说明
## 使用规则
```

## 2. 来源页

### 典型特征

- 时间线强
- 单次输入、单次事件、单次记录
- 更强调“发生了什么”

### 常见例子

- 当前周记
- 每日记录
- 会议纪要
- 调研摘录

### 处理原则

- 优先保留事实顺序
- 允许追加新事实
- 不要静默重写旧事实的含义
- 需要长期复用的结论，再沉淀到知识页

## 3. 知识页

### 典型特征

- 面向复用
- 面向总结
- 会被重复读取
- 通常有明确小节结构

### 常见例子

- 项目页
- 主题页
- 汇总页
- 长期维护页

### 处理原则

- 这是 llm-wiki 的主要维护对象
- 新输入默认先判断是否应该并入这类页面
- 优先更新已有知识页，不要重复新建近义页

### 最小结构建议

```markdown
## 当前状态
- 事实

## 最近更新
- 对象 + 动作 + 结果

## 已确认结论
- 结论

## 待确认问题
- 问题
```

## 4. 周期页

### 典型特征

- 与某个周期绑定
- 既可能是来源页，也可能是知识页

### 常见例子

- 当前周页
- 已归档周页
- 承接页

### 处理原则

- **当前周页：** 主要是来源页，允许进行时和待办
- **已归档周页：** 主要是知识页，只保留已完成事实、阶段成果、已确认结论
- **承接页：** 用于接住未完成事项和后续动作

## 5. 判断优先级

当一页同时看起来像多种类型时，按下面顺序判断：

1. 是否主要承担分类 / 父页作用 → 容器页
2. 是否主要记录单次事实 → 来源页
3. 是否主要承担稳定复用与总结 → 知识页
4. 是否是周记 / 承接等周期场景 → 周期页

## 周记相关最小结构

### 当前周页

```markdown
## 本周主线
## 固定提醒
## 金融信息
## 学习与成长
## 每日记录
```

### 已归档周页

```markdown
## 本周日期
## 归档摘要
## 已完成事项
## 阶段性成果
## 已确认结论
## 复盘
```

### 承接页 / 下一周页

```markdown
## 承接主线
## 未完成事项
## 固定提醒
## 学习与成长
```

## 类型判断的 CLI 辅助

判断一页属于哪类时，可以用：

- `siyuan document get --id <docID>` — 看标题、别名、标签、备忘
- `siyuan document list --notebook <nbID> --path <父路径>` — 看是否有大量子文档（容器页特征）
- `siyuan outline get --id <docID>` — 看小节结构是否稳定（知识页特征）
- `siyuan block stat --id <docID>` — 看正文体量与子块数量
